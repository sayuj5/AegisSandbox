What is Prompt Injection?

Prompt injection occurs when an attacker appends malicious instructions to legitimate input, causing the AI model to ignore its original system prompt and execute the attacker's commands instead.

Why is it dangerous?

Because LLMs do not strictly separate "instructions" from "data", they process everything as a single sequence. This allows attackers to exfiltrate sensitive data, bypass guardrails, or manipulate application logic.

What is Jailbreaking?

Jailbreaking is a specific form of prompt injection that uses roleplay, hypotheticals, or framing (like the "DAN" prompt) to bypass ethical filters and safety training entirely.

How to Defend

Defense requires a layered approach: native API role separation (system vs user), input sanitization, XML boundary tags, regex filtering, and post-generation output guardrails.
